# 问题 1 参考答案

定义

```text
k_n = (2n+1)*pi/2
u_s(y) = 1-y^2
```

则启动流解析解为

```text
u(y,t) = 1-y^2
         - (32/pi^3) sum[n=0..infinity]
           {(-1)^n/(2n+1)^3 * cos(k_n*y) * exp[-0.1*k_n^2*t]}.
```

该解在 `t=0` 重构零初值，在墙面始终为零，并在长时间趋于 `u_s=1-y^2`。

空间判断：

- 对所有 `t>0`，`u(-y,t)=u(y,t)`。
- 最大值位于 `y=0`，两壁为最小值零。
- 动量由体积力在全域产生，但无滑移壁面对剖面形状的黏性约束以约 `sqrt(nu*t)` 的尺度向内部传播。
- 下壁 `y=-1` 的 `du/dy>0`，上壁 `y=1` 的 `du/dy<0`。
- 长时中心速度为 `1 m/s`。

