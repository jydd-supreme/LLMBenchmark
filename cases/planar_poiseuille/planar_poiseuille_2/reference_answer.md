# 问题 2 参考答案

初始扰动恰好是满足两壁齐次边界条件的第一对称本征函数，因此

```text
u(y,t) = 1-y^2
       + 0.30*cos(pi*y/2)*exp(-pi^2*t/40).
```

结论：

- 场始终关于 `y=0` 对称。
- 扰动不平移、不展宽；其空间形状不变，只有幅值指数衰减。
- 除墙面外没有新增固定节点；墙面 `y=+-1` 始终为零。
- 半衰期为 `t_half=40*ln(2)/pi^2 = 2.809... s`。
- 中心速度为 `u(0,t)=1+0.30*exp(-pi^2*t/40)`，从 `1.30 m/s` 单调降低到 `1 m/s`。
