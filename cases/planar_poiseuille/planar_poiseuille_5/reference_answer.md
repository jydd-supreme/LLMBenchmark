# 问题 5 参考答案

令 `k_n=(2n+1)pi/2`，反向新稳态为 `u_s^-=-(1-y^2)`。初始场与新稳态之差是 `2(1-y^2)`，因此

```text
u(y,t) = -(1-y^2)
 + (64/pi^3) sum[n=0..infinity]
   {(-1)^n/(2n+1)^3 * cos(k_n*y) * exp[-0.1*k_n^2*t]}.
```

空间结论：

- 速度场始终关于 `y=0` 对称。
- 驱动力反转后，壁面处速度仍为零，但壁面剪切和邻壁流体最先响应；反流区从两壁附近产生并向中心扩张。
- 在一段时间内会出现“近壁负速度、中心正速度”的共存状态，并有两个关于中心对称的内部零速界面。
- 两个内部零速界面随时间向中心移动，最终合并并消失；之后除墙面外全截面反向。
- 长时间极限是 `u=-(1-y^2)`，中心速度为 `-1 m/s`。
- 中心换向时刻由 `u(0,t)=0` 的级数方程确定，结果为 `t_c=2.9366158238 s`。
- 单位展向宽度流量为

```text
Q(t) = -4/3
     + (256/pi^4) sum[n=0..infinity]
       {exp[-0.1*k_n^2*t]/(2n+1)^4}.
```

  由 `Q(t_Q)=0` 得 `t_Q=2.7503837600 s`。因此整体流量先变号，中心点稍后才变号；这对应近壁反流已经足够强、但中心仍保持正速度的阶段。
