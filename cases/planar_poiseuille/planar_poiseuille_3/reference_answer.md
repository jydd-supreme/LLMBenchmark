# 问题 3 参考答案

解析解为

```text
u(y,t) = 1-y^2 + 0.40*sin(pi*y)*exp(-pi^2*t/10).
```

空间结论：

- 对称部分是 `1-y^2`，反对称部分是后面的正弦项。
- `y=-1,0,1` 是扰动节点；特别地，中心速度对所有时间均为 `u(0,t)=1 m/s`。
- 正弦项在 `0<y<1` 为正，在 `-1<y<0` 为负，因此全局最大值初期位于上半通道。
- 最大值位置满足

```text
-2*y + 0.40*pi*exp(-pi^2*t/10)*cos(pi*y) = 0.
```

  它随扰动衰减逐渐移向 `y=0`，而不是以固定速度横向平移。
- 反对称幅值按 `exp(-pi^2*t/10)` 衰减，所以长时间只剩对称抛物线。
