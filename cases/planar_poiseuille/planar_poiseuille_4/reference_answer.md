# 问题 4 参考答案

令 `k_n=(2n+1)pi/2`。稳态抛物线及塞状初值分别展开后得到

```text
u(y,t) = 1-y^2
 + sum[n=0..infinity] (-1)^n *
   [3.2/((2n+1)pi) - 32/((2n+1)^3*pi^3)]
   * cos(k_n*y) * exp(-0.1*k_n^2*t).
```

解释：

- 常数内部初值在墙面与 Dirichlet 条件不相容，但热方程型问题允许这种初边值角点不相容；任意 `t>0` 解都会被立即平滑，并严格满足墙面条件。
- 速度剖面始终关于中心线对称。
- 早期变化集中在两壁附近，黏性影响厚度为 `O(sqrt(nu*t))`。
- 本组参数下中心速度从 `0.8 m/s` 单调增加并从下方趋于 `1 m/s`；例如 `t=0.05,0.5,2,10 s` 时中心速度分别约为 `0.81, 0.8974516, 0.9882356, 0.9988587 m/s`。这个结论来自完整模态和，不能仅由初值小于终值来猜测。
- 最终速度为 `1-y^2`。
